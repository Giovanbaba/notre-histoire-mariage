# E-mails transactionnels Éclat

Expéditeur prévu : `Éclat <notifications@domaine-eclat.be>` ; réponses vers `privacy@laura-giova.be` pendant le pilote.

## Cycle principal

- Bienvenue : compte créé, adresse du site, étapes initiales.
- Validation e-mail : lien unique expirant.
- Connexion inhabituelle : date, appareil approximatif, bouton de sécurisation.
- Réinitialisation : jeton unique valable 30 minutes.
- Quota 80 % : recommander export/nettoyage/extension.
- Quota 95 % : avertir du blocage imminent.
- RSVP reçu : résumé sans exposer les données sensibles dans l'objet.
- Export prêt : lien signé court.
- Suppression : J-365, J-120, J-30, J-7, J-1/24 h.
- Suppression terminée : confirmation et référence d'audit, sans conserver les médias.
